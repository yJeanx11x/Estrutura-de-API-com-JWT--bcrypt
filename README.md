🧠 2. Entende o fluxo (sem complicar)

Antes de codar, grava isso:

Usuário cria conta → senha é criptografada com bcrypt
Usuário faz login → você compara a senha com bcrypt
Se estiver certo → gera um JWT
Esse token vai ser usado pra acessar rotas protegidas
